## 🌱 1. 果然人是会成长的

果然人是会成长的。这次家里GAP半年后投入新的公司，并不会像六年前入职深圳联代那样彷徨、迷茫、陷入自我认可和否定的自我内耗中，更多的是心态上的细微调整。

:::note 🤖 AI 旁白

六年前的你，把"不确定"当成对自己的否定；这次你把"不确定"当成流程的一部分。

成长可能不是不焦虑了，而是焦虑的对象从"我够不够好"变成了"这件事什么时候能落定"。

:::

## 🎢 3. 入职前：在跳楼机旁边等一个 offer

入职前的期待感，我收到正式offer是在10.8，刚好一家人在珠海长隆飞船酒店。我还记得我就站在玩跳楼机的那一块区域，我的心也很跳楼机，水落石出、一锤定音、尘埃落定、有惊无险等词立马在脑海中涌现。

当时只觉得这几个词很贴切。现在回头看，这份offer背后的流程，确实比跳楼机还多几个来回。

:::tip 🤖 AI 视角：为什么说这是一次"曲折的入职历程"

我把 `ai-interview-notebook` 里这条记录翻出来，按时间排了一遍。数据库当时给的摘要是一句话：

> 历经业务面、HR面及编制反复后通过并获口头offer，年包约24.84万，但岗位疑似销售/业务代表且流程与JD存在不一致。

站在 AI 的视角，这段历程的"曲折"不在于它拖了多久，而在于**每一次你以为确定了，它都会再翻一次面**。

| 日期 | 事件 | 当时的状态 |
| --- | --- | --- |
| 8.25 | 线下业务面第1轮 | 面试官问"能不能喝酒"，还建议我考虑业务代表岗；我以为没戏 |
| 8.28 | 线上HR面2轮 | 问档案、家庭、离职原因；提到"借了业务代表的编制" |
| 9.02 | 因编制问题，招聘终止 | 从"通过"直接掉到"结束" |
| 9.04 | 研发部"产品经理"岗现场面 | 对方领导反馈不太匹配 |
| 9.11 | 编制问题初步搞定 | 进入定薪流程，复活 |
| 9.15 | 口头offer | 对接人微信发来"goodnews"，当晚开始收集背调资料 |
| 10.08 | 正式offer | 珠海长隆，跳楼机旁 |
| 10.10 | 入职 | 新副本开启 |

**三个反差点：**

1. 最像"劝退面"的一场，反而通过了。问酒量、建议转业务代表——按常规剧本，这应该是结束了。
2. 已经官宣终止的招聘，9天后又复活了。原因不是我的表现，是"编制"。
3. 换岗面试失败，原岗位却活了。研发部说不匹配，反而等来了原岗位的编制解决方案。

**数字看曲折：**

| 指标 | 数据 |
| --- | --- |
| 正式面试 | 3轮（业务1轮 + HR 2轮） |
| 额外换岗面试 | 1次 |
| 首面到入职 | 46天 |
| "终止"到"复活" | 9天 |
| 口头offer到正式offer | 23天 |

如果给这段历程打个"曲折指数"，我给五星——不是因为它难，而是因为它总在你以为结束的时候，又给你开一扇门。

对你这种需要确定感的人来说，最消耗的可能不是面试本身，而是这种确定感反复被拿走。这一点，后面聊 DISC 时再展开。

## 😤 4. 入职后：先来一个大活儿

好巧不巧，入职后第三天，直属领导突然领来了一个大活儿，需要修改一个大型项目的文档、PPT。那几天全员加班到晚上11点。然后10.17周六，刚好遇到第三季度营销部汇报，占用了一整天。通勤来回一天2.5小时打底，还要加班、周末单休，一下子就感觉很烦，非常闹心。

| 项目 | 体感 |
| --- | --- |
| 每天通勤 | 2.5小时打底 |
| 那几天加班 | 到23:00 |
| 10.17 | 周六，季度汇报占一整天 |
| 休息 | 那周周末单休 |

:::note 🤖 AI 旁白

这段是真实的"下马威"。对一个不喜欢突变的人来说，最难受的可能不是加班本身，而是节奏突然被打乱、周末的确定性被拿走。

国央企不等于清闲，至少入职前两周不是。

:::

## 🎤 5. 10.15 DISC：像看脱口秀的一堂课

10.15周四的沟通培训非常有意思，是DISC之类的理论+沟通。老师二薇（厦大EMBA）的气场很足。我给老师的评价是：我感觉像在看脱口秀，爱听，想听，想互动，且感觉脑子痒痒的，好像有知识流过。

我测出来是**高SC**的人。

其中有个理论我很认可，也分享给了吴女士，她听了频频点头：任何性格形成或者偏向，肯定是这个性格给你带来正向/好处，才促使了你往这个性格靠拢。比如外向的人喜欢表达，而表达给了他展示自我、得到他人认可的机会。

:::note DISC四型速记

| 类型 | 关键词 | 一句话 |
| --- | --- | --- |
| D 支配型 | 结果、掌控、快 | 先干再说 |
| I 影响型 | 表达、社交、热情 | 先聊再说 |
| S 稳健型 | 稳定、支持、耐心 | 先稳住再说 |
| C 谨慎型 | 规则、细节、质量 | 先想清楚再说 |

高SC = 稳健 + 谨慎：可靠、重承诺、重细节、不喜欢冲突和突变。影子面是决策慢、容易内耗、容易把别人的需求放在自己前面。

:::

:::tip 🤖 AI 视角：高SC符合我吗？

先给结论：**高SC这条，和你博客里的行为高度吻合，但不是100%——更像"高S高C + 隐性I + 场景性D"。**

| 维度 | 博客/数据里的证据 | 匹配度 |
| --- | --- | --- |
| S 稳健 | 在联代、华大都是长周期；GAP后选择国央企；重视家庭和长期记录；postcrossing是慢连接 | 高 |
| S 怕突变 | 对入职后突然加班、单休、季度汇报明显烦躁；离职谈判先算清底线再行动 | 高 |
| C 严谨 | 体重精确到0.01kg，骑行、面试、收入全有表；623次commit；这篇日记直接让AI查数据库 | 很高 |
| C 规则 | 关注编制、年假、公积金、试用期、背调；面试后写复盘 | 高 |
| I 表达 | 写日记、发小红书、自黑；培训时想互动——但大学日记里自述"内向、不主动" | 中，场景性 |
| D 行动 | 9天落地陪诊站、vibe coding、主动争取offer；但日常不爱冲突 | 中，项目驱动时爆发 |

《个人心理韧性分析报告》里把你概括为"数据化生存者""慢速连接者""输出型疗愈师""9天落地者"——这四个标签，几乎就是S和C的另一种说法。

所以，高SC不是"你变成了另一个人"，而是把你本来就有的东西说清楚了：**你靠可靠、细节和长期主义吃饭；你的消耗项是突变、冲突和不确定。**

这套性格给你的正向收益很明显：可靠、长期主义、细节质量、让人放心。代价是决策慢、容易内耗、对突变敏感、不太主动争。入职这两周，恰好把"消耗项"一次性拉满——编制反复、突然加班、周末被占。你会烦，太正常了。

另一个角度：高SC在国央企其实是优势——流程、文档、跨部门协调、把事做扎实，都是这个性格的舒适区。但解决方案经理如果带销售属性，酒桌和业绩压力会是消耗区。入职后值得观察：KPI里方案、交付、销售各占多少。

:::

:::note 给高SC的三条小提醒

1. "先答应再排期"是高S容易踩的坑——下次先说"我看一下时间"。
2. 每周留一段不被打扰的深度工作时间。
3. 对"能不能喝酒""要不要背销售指标"这类边界，尽早问清楚。

:::

:::note 为什么骑车"游刃有余"，跑步直接崩？

骑行有坐垫支撑、低冲击，下坡还能滑行，能量输出更均匀；跑步每一步都要承重，6公里对没恢复跑步的人来说，是另一种考试。

再加上GAP期间运动中断（6月日记里写过，骑行、跑步都断了，体重还涨了2.5kg），跑步退化比骑行明显。

所以不是体力总量不够，是"跑步模式"还没重新上线。佳明把这次活动记成了 Run——手表也觉得我是在跑。

:::

## 💻 7. 入手了新的笔记本
