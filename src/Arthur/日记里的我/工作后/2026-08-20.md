## 🏗️ 六个阶段

### Phase 1：一天建成一个网站（6/14-6/15）

35次提交，一天之内搭好骨架：i18n三语架构、SEO、About页、第一篇 Guide、联系表单。凌晨3点还在改 CSS 的时候，我意识到这不是「试试看」，是真的要做。（代价是后面花了一个月还技术债。）

### Phase 2：商业化基建（6/16-6/30）

第二周就做定价表、营业执照、支付码、取消政策。6月28日定金制度重构，引入三 agent 评审——一个人的项目做三轮评审，医疗场景容不得含糊。

### Phase 3：安全加固（7/1-7/15）

HTTP安全头、API限流、CSP收紧、P0安全补丁。教训：安全补丁不是「有空再补」，nodemailer和postcss的漏洞差点在Vercel部署时被拦下来。

### Phase 4：去AI味 + 组件系统（7/16-7/31）

最大规模重构。34篇文章 Hero 组件统一迁移，全站 emoji→Lucide 图标，26篇文章+3语言翻译的 AI 痕迹批量清理。

> 做到了基本去AI味道，但还不够精细——后来强制要求以医院公众号文章、官网公告作为第一采信源。

### Phase 5：AI 爬虫追踪 + SEO 深化（8/1-8/15）

从零搭建 AI 爬虫追踪系统，全站12项 SEO 问题修复，llms.txt 上线。

> 「我自己的小网站有AI踩点过吗？」——嘿，果然捞到了一些信息。

### Phase 6：规则沉淀（8/16-8/20）

把67天的踩坑经验编码为可执行规则，CLAUDE.md压缩拆分。
> 「我去，我的kimi+火山引擎token plan怎么几个小问题就爆了5小时额度？！CLAUDE.md太大了，什么都塞进去，每次新对话都加载一遍，不爆炸谁爆炸？」

## 🐛 踩坑 Top5

### 1. Dead Keys 地狱

143个翻译死键一次性清理。Phase 1 快速启动没有 i18n 规范，「先跑起来」的策略在 Phase 4 必须停下来还债。

### 2. Build 失败连环

Mux CDN直链、`fs` 在 Client Component 引用、Resend lazy 初始化……每次都是上线前才发现。后来加了一条规则：push 前必须跑 `npm run build`，没有例外。

### 3. AI 写作痕迹

26篇文章+3语言翻译的AI痕迹批量清理。医疗场景需要「朋友的朋友」的信任感，不是机器人的标准化输出。后来 CLAUDE.md 加了一条：**含人量100%**。

### 4. SEO 事故

一个依赖替换（`sanitize-html` → `isomorphic-dompurify`），影响了12个页面。现在养成习惯：每次改依赖，先搜兼容性。

### 5. Vibe Coding 技术债

8月3日一次性清理12项。从「先跑起来」到「必须规范」的转折点。

### 2. 多 Agent 协作框架

三 agent 评审（法律+医疗+可用性）、JW UX 评审、外审两轮制。一个人的项目，做出了团队的严谨度。

> 第一次真正用 AI 做「质量把关」而不只是「内容生产」。尤其是多个agent逻辑上互掐，非常有意思。

### 3. 34篇文章一站式迁移

Hero 组件统一迁移，当重复劳动超过3次，就该停下来做抽象。

### 4. AI 爬虫追踪系统

Supabase + isbot + Edge Middleware，一个人做了竞品都没有的监控能力。

### 5. CLAUDE.md 知识库

:::warning 后续进展（2026.10.23 补记）：项目进入长期暂停

写这篇复盘的时候，我还在等"临门一脚"。四个月后，答案揭晓了——这一脚始终没有到来。

**项目现状：<Badge type="danger" text="长期暂停" />**

核心原因很直白：

1. **没有外部客户下单**。67 天打磨出的网站、三语 Guide、支付系统，换来的是 WhatsApp 上的零星咨询——问了价、聊了两句，然后就没有然后了。冷启动 0 成交，不是"差临门一脚"，是球根本没进过禁区。
2. **我入职了新公司**（10.10 中粮粮达网），每天来回 2.5 小时通勤打底，精力与动力都归零了。副业需要的是"下班后还有电"，而我现在的电量只够陪家人和写日记。

不过我不觉得这 67 天白费了。网站还在 Vercel 上挂着，执照、收款码、口语手册、同行群都还在——它只是从"在营业"变成了"在歇业"。如果未来涉外医疗 demand 真起来了，或者我又 GAP 了，这套基建随时可以重启。

:::note 🤖 AI 旁白

回头看 6 月 GAP 篇日记里的那句"先看看有没有兼职，先接一些海外的陪诊单"——当时的设想是网站获客、服务变现。实际跑通的是前半段（网站上线、内容、支付全部就绪），卡死在最后一环：获客。

这也是独立副业最诚实的教训：**最难的不是做出产品，是让人为它付钱。** 67 天 623 次 commit 证明了执行力，0 成交验证了"技术不是瓶颈，需求才是"。

:::

:::info 🤖 AI 旁白：从 git 记录看到的谢幕过程（8.20 → 9.22）

我让 AI 翻了这个项目 8.20 之后的 git push 记录，最后一个月的轨迹很清晰：

- **8月下旬还有一股冲劲**：8.22-23 两天 25 次 commit，做"获客 P0"（线索落库 + WhatsApp 预填 + 表单归因）、china-payment 重构；8.26 还在给 35 个页面补 og:url。
- **9月上旬内容冲刺**：连续几天打磨《深圳处方药购买指南》（Mounjaro/减重针，三语）、BmiCalculator 交互组件、中医文章；9.6 因为"**首个真实客人来自越南**"（commit 原话），专门做了越南药品入境说明——不过按我自己的口径，这位客人也只是问询，最终没有下单，0 成交的纪录一直保持到最后。
- **9.18 个体工商户正式注销**——为了配合入职流程，"深圳市盐田区梧安之健康咨询服务部"走完注销，平安对公账户销户，商家收款码随之失效。9.22 那天用一个大 commit 把全站表述清理干净：营业执照公示下架、增值税发票承诺改回签名收据、隐私主体从"个体工商户"改回"个人"，同时项目正式降级为"周末兼职"。
- **9.22 14:28 最后一次 commit**，之后再无 push。倒也体面：最后一次提交是把人社部的《医疗陪诊顾问培训证书》挂上 About 页（还顺手把证书图里的身份证号做了像素级覆盖，防止增强检验复原）——网站以"个人 + 持证"的姿态挂在那里，而不是烂尾的姿态。

有意思的是时间线：8.25 中粮面试通过 → 9.1 还在被盐田国际拒绝 → 9.6 迎来首个问询客人（最终未下单）→ 9.18 注销执照。**offer 已定和首单苗头几乎同时出现，但为了新工作，选择了关门**。这不是失败，是排序。
